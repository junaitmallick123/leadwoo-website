# LeadWoo Website

Private source repository for the LeadWoo marketing website.

## Included pages

- Homepage
- LinkedIn, Email, WhatsApp, Voice AI, WooAgent, Support Agent, and Website Builder pages
- Pricing (`/plans`)
- About and Blog
- Privacy Policy and Terms of Service

## Local development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

## Production validation

```bash
npm run lint
npm test
```

The current public review deployment is available at https://leadwoo-landing.junaitmallick123.chatgpt.site.
